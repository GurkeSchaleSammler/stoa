Stoa Query Language

StoaQL

StoaQL ist die kompakte, deklarative Command-Sprache von Stoasis. Mit ihr erstellst, findest, verbindest und ordnest du Pins – in einer einzigen, lesbaren Zeile.

Schnellstart

Die erste Query

Öffne ein Board und wähle in der Toolbar das Terminal-Symbol. Die Konsole ist automatisch mit diesem Board verbunden – USE ist dort nicht nötig.

01

Pin erstellen

Ein String nach ADD wird immer zu einer Notiz.

02

Alias vergeben

Mit AS kannst du den neuen Pin in derselben Query referenzieren.

03

Aktionen verbinden

Ein Semikolon trennt mehrere atomar ausgeführte Statements.

Board-Kontext inklusive

Die Board-Konsole sendet die ID des offenen Boards als context.collectionId. Außerhalb der Konsole setzt du den Kontext mit USE "Board", einem expliziten TO oder über die API.

Grundlagen

Eine Domain-Sprache, kein SQL

StoaQL beschreibt Absichten in Stoasis-Begriffen. Es kennt Pins, Boards, Verbindungen und Layouts – aber keine Tabellen, Spalten oder freien Datenbankabfragen.

Einzeilig

Eine Query bleibt in einer Zeile. Mehrere Statements werden mit ; getrennt.

Explizite Typen

ADD erzeugt eine Notiz, LINK einen Link. Es gibt keine Magic Detection.

Atomar

Schlägt ein Statement fehl, wird die gesamte Query zurückgerollt.

Autocomplete-first

Die lokale Completion kennt Keywords, Boardnamen und Aliases der aktuellen Query.

Sprachsyntax

Bausteine

Strings "SSH" Immer in doppelten Anführungszeichen
Escaping "Sag: \"Hallo\"" \", \\, \n, \r und \t
Aliases ssh_key1 Buchstabe oder _, danach auch Ziffern
Keywords ADD · add · Add Case-insensitiv; die Doku zeigt die kanonische Großschreibung
Statements ADD "A"; ADD "B"; Mit ; getrennt; das letzte Semikolon ist optional
Referenzen ssh · "pin-123" Alias ohne, bestehende ID mit Anführungszeichen

Vereinfachte Grammatik

Optionen in eckigen Klammern sind optional. Geschweifte Klammern bezeichnen eine beliebige Wiederholung und sind keine Zeichen, die du eingibst.

Referenz

Befehle

StoaQL 1.0 besteht aus elf Befehlen. Optionen müssen in der dokumentierten Reihenfolge stehen, damit Queries eindeutig und schnell zu lesen bleiben.

@for (command of commands; track command.name) { }

HTTP API

POST /api/v1/query

Der authentifizierte Endpoint akzeptiert dieselbe Sprache wie die Board-Konsole. Alle Stoa-Berechtigungen werden vor und während der Ausführung geprüft.

Request

languageVersion, atomic und return haben die gezeigten Standardwerte. context.collectionId setzt das aktuelle Board.

Response

Schreibaktionen erscheinen unter operations, Leseergebnisse unter results. aliases enthält die aufgelösten IDs.

FeldTypBedeutung
querystringDie StoaQL-Zeile; erforderlich
languageVersion"1.0"Aktuell unterstützte Sprachversion
dryRunbooleanValidiert und führt aus, rollt Änderungen danach zurück
atomictrueFür Version 1.0 immer atomar
return"operations"Aktuell einziger Rückgabemodus
idempotencyKeystring?1–128 Zeichen; verhindert doppelte Schreibvorgänge
context.collectionIdstring?Board-ID oder auflösbarer Boardname als Startkontext

Query-Verlauf

Pro Person und Board

Die Board-Konsole speichert erfolgreiche, fehlgeschlagene und als Dry Run ausgeführte Queries. Der Verlauf ist privat: Auch in einem geteilten Board sieht jede Person nur ihre eigenen Einträge. Die neuesten 30 Queries werden in der Konsole angezeigt.

MethodeEndpointBedeutung
GET/api/v1/query/historyLiest den eigenen Verlauf für collectionId; limit ist optional (1–100).
DELETE/api/v1/query/historyLöscht den eigenen Verlauf des angegebenen Boards.

Diagnose

Fehler & Limits

Fehler zeigen Code, Spalte und optional den Statement-Index. Ein Hint beschreibt meist direkt den nächsten sinnvollen Schritt.

100 KBmaximale Query-Länge
500Statements pro Query
1–10zulässige Verbindungstiefe

5 sTransaktions-Timeout

Häufige Codes

STOAQL_PARSE_ERROR
Query-Form oder Länge ist ungültig.
STOAQL_UNEXPECTED_TOKEN
Ein Zeichen oder Keyword steht nicht an dieser Position.
STOAQL_UNKNOWN_ALIAS
Der Alias wurde in dieser Query noch nicht mit AS definiert.
STOAQL_BOARD_NOT_SELECTED
Es fehlt ein Board-Kontext über Konsole, API, USE oder TO.
STOAQL_REFERENCE_NOT_FOUND
Der referenzierte Pin oder das Board existiert nicht oder ist nicht sichtbar.
STOAQL_PERMISSION_DENIED
Die aktuelle Person darf die angeforderte Aktion nicht ausführen.
STOAQL_INVALID_PROPERTY
Wert, Feld, URL, Option oder Request-Eigenschaft ist ungültig.
STOAQL_IDEMPOTENCY_CONFLICT
Ein Key wurde bereits für eine andere Query verwendet.

Sicherheit

Nur Stoa-Domain-Operationen

StoaQL ist kein SQL-Passthrough. Der Parser kennt keine Tabellen oder Spalten. Jede Aktion läuft über die bestehenden Domain-Services, Board-Grenzen und Berechtigungen von Stoasis.

Nicht Teil von Version 1.0 sind Foto-Uploads, verschachtelte Blöcke, freie WHERE-Ausdrücke und das Löschen kompletter Boards.
